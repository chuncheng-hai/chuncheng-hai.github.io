电子书转PDF
calibre
可编辑电子书的元数据，如补充元数据中的作者，电子书封面
单本调格式：calibre GUI
批量调格式：calibre CLI ebook-convert

```bash
echo 'export PATH="/Applications/calibre.app/Contents/MacOS:$PATH"' >> ~/.zshrc
source ~/.zshrc

ebook-convert --version

ebook-convert 美国反对美国\ .epub 美国反对美国\ .pdf
```
