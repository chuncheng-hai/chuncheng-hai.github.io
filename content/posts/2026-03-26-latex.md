LaTex

TeX 的源代码是后缀为 .tex 的纯文本文件

## 一个LaTex的MVP
在Tex中所有命令(或称控制序列)以 \ 开头
TeX的注释 以百分号 % 开头
控制序列
```latex
\documentclass{article}
% 导言区

\begin{document}
Hello,world.
\end{document}
```

{{< compare title="最小 LaTeX 文档：源码与编译结果" left="源码" right="编译后你会看到什么" >}}
```latex
\documentclass{article}

\begin{document}
Hello, world.
\end{document}
```
<!--split-->
Hello, world.
{{< /compare >}}

标题结构
```latex
\section{A first-level heading}
\subsection{A second-level heading}
\subsubsection{A third-level heading}
```

{{< compare title="标题命令与页面结构对照" left="LaTeX 命令" right="读者看到的层级" >}}

插入代码
```latex
\begin{verbatim}

\end{verbatim}
```
