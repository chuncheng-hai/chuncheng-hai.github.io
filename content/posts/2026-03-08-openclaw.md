## 基于MAC M3 部署

芯片：Apple M3
系统：Tahoe 26.3

环境配置

```bash
# 安装Node.js与Git
brew install node
```

### npm淘宝镜像安装

`npm install -g openclaw@latest --registry=https://registry.npmmirror.com`

### 源码编译安装

```zsh
# git克隆openclaw源码
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# 基于淘宝npm镜像源安装pnpm
npm install -g pnpm --registry=https://registry.npmmirror.com

pnpm config set registry https://registry.npmmirror.com

# 安装openclaw项目所有 Node 依赖
pnpm install

# 构建 OpenClaw Web UI
pnpm ui:build

# 编译 TypeScript → JavaScript
pnpm build

# 初始化 OpenClaw + 安装系统服务
pnpm openclaw onboard --install-daemon
```

## 对接Telegram 

OpenClaw 连接到真实的即时通讯平台。将收到的私信视为不可信输入，因此需要配置allowFrom用户id。
OpenClaw连接Telegram会被GFW拦截，因此需要配置连接走channels代理。

vim ~/.openclaw/openclaw.json，找到channels配置块区域，追加如下配置(http://127.0.0.1:7892为笔者代理端口，需要具体问题具体分析修改)。

```bash
 "allowFrom": [
        telegram用户id
      ],
"proxy": "http://127.0.0.1:7892"
```

allowFrom 解决的是 谁可以聊天
pair code 解决的是 哪个客户端可以成为设备
