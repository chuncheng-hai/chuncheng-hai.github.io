## 镜像配置

在 AI 开发过程中，Hugging Face 作为全球顶尖的开源模型与数据集社区，几乎是每个AI有志青年的必备工具。然而大陆用户在访问官方仓库时，由于GFW，常常遭遇网络超时、下载中断、速度缓慢等问题，尤其是动辄数 GB 的大模型文件，往往耗费数小时仍无法完成下载。

国内主流 Hugging Face 镜像平台
- [HF-Mirror](https://hf-mirror.com) 目前国内最主流的 Hugging Face 公益镜像站
- [阿里魔搭社区（ModelScope）](https://modelscope.cn)

hfd是Hugging Face专用 的高速下载脚本，基于aria2c实现多连接下载
```bash
# 下载hfd工具
wget https://hf-mirror.com/hfd/hfd.sh
chmod a+x hfd.sh
# 配置环境变量
sudo mv hfd.sh /usr/local/bin/hfd

# 安装 aria2c
brew install aria2

# 设置镜像
export HF_ENDPOINT='https://hf-mirror.com'

# 下载qwen-3-14b模型，约10G，预计下载1小时
hfd lm-kit/qwen-3-14b-instruct-gguf \
  --include "*Q5_K_M.gguf" \
  --local-dir ./qwen3-14b-instruct
```

## 安装llama.cpp

```bash
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

cmake -B build
cmake --build build --config Release

uv pip install -r requirements.txt

python convert.py ../Qwen3-14B-Q5_K_M.gguf --outfile Qwen3-14B-Q5_K_M.fp16.gguf
```
