```bash
# 安装uv
curl -LsSf https://astral.sh/uv/install.sh | sh

uv pip install jupyter  jupyterlab-language-pack-zh-CN  -i https://pypi.tuna.tsinghua.edu.cn/simple

~/.venv/bin/jupyter notebook --ip=0.0.0.0 --port=8888 --no-browser --allow-root

```

如何在 Jupyter Notebook 中执行 Bash（Shell）命令
在命令前加 !

魔法命令：%system 或 %%bash

```python
%%bash
echo "当前目录:"
pwd
```

```python
files = %system ls
print(files)
```
