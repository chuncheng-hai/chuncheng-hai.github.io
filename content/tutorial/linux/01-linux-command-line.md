## 学习目标

- 会用 `pwd`、`ls`、`cd`、`mkdir`、`cp`、`mv`、`rm`。  
- 理解绝对路径与相对路径。  

## 最小命令集

```bash
pwd
ls -la
cd /var/log
mkdir demo
cp a.txt b.txt
mv b.txt c.txt
rm c.txt
```

## 实践建议

每天保持 15 分钟命令行练习，先求熟练再求复杂。
