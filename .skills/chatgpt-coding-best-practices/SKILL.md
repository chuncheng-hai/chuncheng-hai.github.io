# ChatGPT 编程最佳实践

当用户要求“让 ChatGPT 帮我写代码/改代码/做重构”时使用此技能。

## 触发词模板

- “帮我写一个提示词，让 ChatGPT 更会写代码”
- “给我一套让 ChatGPT 编程的最佳实践”
- “如何让大模型改代码更稳定”
- “我想让 ChatGPT 按工程规范做开发”

## 实施流程

1. 先定边界：目标、输入、输出、不可变约束。
2. 给足上下文：相关文件、运行命令、报错日志、验收标准。
3. 要求最小改动：优先局部修复，避免无关重构。
4. 明确验证：让模型给出可执行的构建/测试命令。
5. 做回归检查：功能、性能、兼容性、异常分支。
6. 每次代码修改后，同步更新 `README.md`：
   - 变更了功能：补“功能说明/使用方式”
   - 变更了命令：补“本地开发/发布命令”
   - 新增了技能或页面：补“目录与入口”

## 推荐提示词骨架

```text
你是资深工程师。请在不改变无关逻辑的前提下完成以下任务：
1) 先简述你对问题的理解与假设；
2) 给出最小可行修改方案；
3) 直接输出具体代码改动（文件路径 + 关键片段）；
4) 给出本地验证命令与预期结果；
5) 标注潜在风险与回滚方案。

项目上下文：
- 技术栈：...
- 相关文件：...
- 当前错误：...
- 验收标准：...
```

## 质量门槛

- 没有验证命令的答案视为不完整。
- 不能解释为什么改动最小的方案，视为不通过。
- 涉及线上风险时，必须包含回滚思路。
- 修改了代码却未更新 `README.md`，视为不通过。
